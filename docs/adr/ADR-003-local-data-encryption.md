# ADR-003: تشفير قاعدة البيانات والملفات المحلية

**الحالة:** قيد التقييم الأمني
**التاريخ:** 26 أغسطس 2026

## السياق

ملف SQLite المحلي والمرفقات قد يحتويان على بيانات تشغيلية حساسة، وهما غير مشفرين بالكامل في الوضع الحالي. تشفير كلمات المرور في شكل hash لا يحمي السجلات أو الملفات إذا نُسخ مجلد التطبيق من جهاز Windows.

## القرار

لا يُضاف تشفير جزئي أو مفتاح ثابت داخل المستودع. يجب اختيار SQLCipher أو تشفير حقول/ملفات مضبوط بمفتاح محفوظ في Windows Credential Manager أو آلية مؤسسية مماثلة، مع تصميم key rotation وrecovery escrow وسياسة فقد المفتاح. يجب أن يشمل التصميم النسخ الاحتياطية وملفات temp وthumbnails وexports، لا قاعدة SQLite الرئيسية فقط.

## التبعات

تشفير البيانات سيؤثر على startup والأداء والنسخ الاحتياطي والتوافق مع الإصدارات القديمة. لذلك بقي خارج الإصلاح السريع في هذه الدورة. إضافة encryption دون خطة استعادة قد تحول تسرب البيانات إلى فقد دائم، ولذلك يجب تقديم migration tool صريح مع backup موثق واختبار restore قبل تفعيله افتراضيًا.

## معايير القبول المستقبلية

يشمل التنفيذ threat model، قياس overhead، key provisioning دون secrets في logs أو Git، ترحيلًا idempotent، تحققًا من checksum بعد فك التشفير، اختبار backup/restore على Windows، وتوثيقًا لما يبقى ظاهرًا في أسماء الملفات أو سجلات التدقيق. لا يُعتبر النظام compliant أو محميًا ضد سرقة الجهاز قبل إكمال هذا المسار.
